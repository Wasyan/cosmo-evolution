# 🌌 COSMOSIS: Эволюция Вселенной

Полноценная браузерная инкрементальная игра (Clicker / Idle Sci-Fi), моделирующая развитие цивилизации от бурения планетарного ядра до управления фундаментальными законами Мультивселенной.

---

## 🚀 Как запустить игру

1. **Самый простой способ**:
   Просто откройте файл [`index.html`](file:///C:/Users/vasya/.gemini/antigravity/scratch/cosmo-evolution/index.html) двойным кликом в любом современном браузере (Chrome, Edge, Firefox, Safari). Игра полностью автономна и не требует сервера.

2. **Запуск через локальный HTTP-сервер (по желанию)**:
   ```powershell
   cd C:\Users\vasya\.gemini\antigravity\scratch\cosmo-evolution
   python -m http.server 8080
   ```
   Затем откройте в браузере `http://localhost:8080`.

## 🪐 Игровая механика и масштабы (Tiers)

### 1. Планетарный уровень (Терра-Прайм)
- **Ресурсы**: 🪨 Минералы, ⚡ Энергия, 🧬 Биомасса.
- **Действие**: Кликайте по планете для бурения и добычи сырья.
- **Постройки**: Автоматические буры, Геотермальные ТЭЦ, Биосферные купола, Космический лифт, Орбитальные города.
- **Прорыв**: Строительство Межпланетного Ковчега открывает доступ к Солнечной системе.

### 2. Звездный уровень (Система Гелиос-Альфа)
- **Ресурсы**: 🔥 Звездная плазма, 🧪 Гелий-3, ⚛️ Антиматерия.
- **Постройки**: Солнечные уловители короны, Атмосферные сифоны газовых гигантов, Орбитальные коллайдеры, Рой Дайсона и Сфера Дайсона.
- **Прорыв**: Сверхсветовой варп-двигатель открывает масштабы Галактики.

### 3. Галактический уровень (Спираль Андромеды-V)
- **Ресурсы**: 🌌 Темная материя, 🌀 Гравитоны, 🧠 Нейросеть Космоса.
- **Постройки**: Экстракторы квазаров, Врата червоточин, Нейрокластеры звезд, Сингулярные сферы вокруг сверхмассивных черных дыр.
- **Прорыв**: Квантовый коллапс пространства.

### 4. Вселенский уровень & Большой Взрыв (Космогенезис / Престиж)
- **Ресурс**: 💥 Искры Творения (Genesis Sparks).
- **Механика Большого Взрыва**: Сжатие Вселенной сбрасывает локальные постройки, конвертируя всю добытую материю в Искры Творения.
- **Великие Физические Константы**:
  - *Квантование Планка*: постоянное умножение силы клика во всех мирах.
  - *Гравитационная гармония*: глобальный пассивный буст всей выработки.
  - *Релятивистский форсаж*: учащение появления комет и космических событий.
  - *Темная экспансия*: постоянная скидка на стоимость всех построек.

## ☄️ Интерактивные события и фичи

1. **Золотые кометы**: Периодически пролетают через космический экран с хвостом из сверкающих частиц. Кликните прямо по комете, чтобы взорвать её и забрать огромный куш ресурсов!
2. **Экстренные космические события**:
   - *Солнечные вспышки* (выбор: перегрузить генераторы или сфокусировать щиты).
   - *Древние зонды чужих* (выбор: расшифровать квантовый архив для бесплатной технологии или разобрать на сырье).
   - *Гравитационные аномалии* (ускорение времени в 3 раза).
   - *Квантовый резонанс бурения* (пятикратный шквал кликов).
3. **Процедурный аудио-синтезатор**: Чистый Web Audio API генерирует космические звуковые эффекты (щелчки, перезвоны покупок, гул варпа, взрывы комет) без внешних файлов. Звук можно выключить кнопкой 🔊 в шапке.
4. **Анимированный Canvas (60 FPS)**: Живой космос с вращающимися телами, орбитами планет, спиральными рукавами галактики и частицами.
5. **Сохранения и оффлайн-прогресс**: Игра сохраняется каждые 5 секунд в `localStorage`, считает накопления за время отсутствия, поддерживает экспорт/импорт ключей сохранения и жесткий сброс.
